# ShiftManager

職員情報、必要人員、勤務ルールをもとに、月間シフトの作成・編集・保存・確認を行う勤務シフト管理アプリです。  
Java／Spring Bootの学習と、業務ルールを伴うWebアプリケーション設計・実装の実践を目的に制作しています。

> 現在開発中です。設計書とソースコードを随時更新しています。

## 主な機能

- ログイン／ログアウト
- 職員の登録・一覧・詳細・編集・無効化
- 無効化した職員の履歴表示
- 部署・年月別のシフト一覧表示
- シフトの手動入力、一時保存、確定、確定解除
- 必要人員の登録と時間帯別の過不足表示
- 勤務ルールに基づくシフト自動生成
- 過去月の保存済みシフト表示と手動訂正

## シフト自動生成で考慮する主なルール

- 手入力済みのシフトを上書きしない
- 希望休・有給を保持する
- パート職員は曜日別の固定勤務時間を反映する
- 夜勤の翌日に「明」を割り当てる
- 日勤の連続勤務は4日までとし、5連勤を避ける
- 正社員は月9日の「休」を確保する
- 必要人員の不足解消を優先し、その後も勤務可能な職員へ割り当てる
- 条件を満たせない場合は警告として表示する

## ゲスト利用

ポートフォリオ確認用のゲストアカウントを用意しています。認証情報は公開環境のログイン画面で確認できます。

ゲストは、シフト一覧・生成・編集、職員一覧・詳細・履歴、職員登録・編集・無効化を利用できます。ゲストアカウント自体は職員一覧およびシフトの自動生成対象には含まれません。

操作内容は保存され、ほかの利用者にも共有されます。登録されている職員情報はすべて架空です。

## ローカルでの実行

### 前提

- JDK 17
- PostgreSQL
- Git

### 手順

1. リポジトリをクローンします。

   ```bash
   git clone https://github.com/yasutomiharuka/ShiftManager.git
   cd ShiftManager
   ```

2. `src/main/resources/application.properties` のデータベース接続情報を、自分の環境に合わせて設定します。

3. アプリケーションを起動します。

   ```bash
   ./gradlew bootRun
   ```

4. ブラウザで `http://localhost:8080/login` を開きます。

WindowsでGradle Wrapperを実行する場合は、`gradlew.bat bootRun` を使用してください。

## テスト

```bash
./gradlew test
```

## 工夫した点

- 要件、業務ルール、画面、API、DB、テストケースをIDで関連付け、実装との対応を追えるようにしています。
- 手入力、希望休、固定勤務などを保護しながら自動生成する優先順位を設計しています。
- 必要人員だけでなく、月9休、連続勤務、夜勤・明けなど複数の条件を扱っています。
- 職員は物理削除せず無効化し、過去のシフト履歴を保持する設計にしています。
- 入力エラー時の画面復帰や一括保存のロールバックを考慮しています。
